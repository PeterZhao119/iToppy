# iToppy Open Skills

这里整理 iToppy 对外开放的制作与接入经验。欢迎按这些约定提交新角色或新 Agent 适配器。

## 技能索引

- [角色形象制作](itoppy-character-production/SKILL.md)：从参考图、动作设计、绿幕视频到透明 Sprite Sheet 和 13 组角色包。
- [Agent 适配器接入](itoppy-agent-adapter/SKILL.md)：从真实日志调研、事件边界、子代理过滤到原生监听、设置菜单和验收。

## 使用建议

- 做角色时，先交付小样让用户确认，再量产整套动作。
- 接 Agent 时，先拿真实日志样本，再实现解析器；没有实机验证的分支明确标记“待实机”。
- 所有生成素材和解析结果都要实际回读或运行验证，不能用“接口成功”代替交付。
- 密钥、私密路径和未确认授权的素材不要写入公开仓库。
